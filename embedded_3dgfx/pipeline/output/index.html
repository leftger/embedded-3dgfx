Pipeline stage 5 — output.

Framebuffer backends (display_backend), triple-buffered presentation (swapchain), async DMA completion slots (completion), and the 2D hud overlay composited over the rendered frame.

§Writing a display backend

The traits below name types from embedded-graphics-framebuf in their signatures, so they are re-exported here: a driver needs exactly one use:

use embedded_3dgfx::pipeline::output::{
    DisplayBackend, DisplayRegion, DmaTransfer, FrameBuf, StandardSwapChain, TransferError,
};
