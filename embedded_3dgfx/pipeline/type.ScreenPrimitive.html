LightmappedTriangle

Perspective-correct textured triangle with baked lightmap.

The final pixel colour is: clamp(surface.sample(su,sv) × lightmap.sample(lu,lv) + dynamic_tint) where × is per-channel normalised multiply. Set lightmap_id = u32::MAX to fall back to full-bright surface colour. Set dynamic_tint = Rgb565::new(0,0,0) for no dynamic lighting.

Per-face brightness multiplier in 0..=255 (255 = no darkening).

§dynamic_tint: Rgb565
